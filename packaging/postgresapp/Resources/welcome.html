pg_pinecone @EXTENSION_VERSION@ for PostgreSQL @PG_MAJOR_VERSION@

You are about to install pg_pinecone for Postgres.app on Apple silicon.

This installer is compatible with Postgres.app 2.8.3 or later.

vector is already included with Postgres.app. After installing, restart the server, then run CREATE EXTENSION vector; and CREATE EXTENSION pg_pinecone;.

Remote tables and the background worker need shared_preload_libraries = 'pg_pinecone' in postgresql.conf and another restart. This installer does not edit postgresql.conf.
