Restart PostgreSQL before using this version

pg_pinecone @EXTENSION_VERSION@ for PostgreSQL @PG_MAJOR_VERSION@ has been installed.

Stop and restart the server before using it. This installer does not edit postgresql.conf.

New install: run CREATE EXTENSION vector; then CREATE EXTENSION pg_pinecone;. vector is already included with Postgres.app. Remote tables and the background worker also need shared_preload_libraries = 'pg_pinecone' in postgresql.conf, then another restart.

Upgrade: restart first, then run ALTER EXTENSION pg_pinecone UPDATE; in every database that uses the extension. Updating while the previous library is still loaded fails and rolls back.
